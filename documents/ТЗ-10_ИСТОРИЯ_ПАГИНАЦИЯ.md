## 📌 ВВЕДЕНИЕ

**Что это?** Оптимизированная загрузка истории сообщений с пагинацией.

**Зачем нужно?**
- Браузер не должен грузить 10000 сообщений сразу
- Должна быть возможность "Загрузить старые сообщения"
- Должна быть кнопка "Обновить" для загрузки новых

**Текущее состояние:**
- ✅ GET /messages существует
- ❌ Нет параметров limit и offset
- ❌ Нет правильной сортировки
- ❌ Фронтенд грузит все сообщения

**Результат после ТЗ-10:**
```
GET /api/rooms/1/messages?limit=50&offset=0
→ Возвращает последние 50 сообщений

GET /api/rooms/1/messages?limit=50&offset=50
→ Возвращает следующие 50 (старые)
```

## 🔧 ШАГ 1: ОБНОВЛЕНИЕ БЭКЕНДА

### Проблема текущего подхода:
```python
# ДО (неправильно):
@router.get("/rooms/{room_id}/messages")
async def get_messages(room_id: int, session: AsyncSession = Depends(get_session)):
    result = await session.execute(
        select(Message).where(Message.room_id == room_id)

```

### Решение:

**Файл:** `backend/api/routes.py`

```python
from typing import List
from pydantic import BaseModel

# Модель ответа для списка сообщений с пагинацией
class MessagesListResponse(BaseModel):
    items: List[dict]  # Сами сообщения
    total: int        # Общее количество в комнате
    limit: int        # Сколько вернули
    offset: int       # С какого начали

@router.get("/rooms/{room_id}/messages", response_model=MessagesListResponse)
async def get_messages(
    room_id: int,
    limit: int = 50,      # По умолчанию 50 сообщений
    offset: int = 0,      # По умолчанию начинаем с 0
    session: AsyncSession = Depends(get_session),
    current_user: User = Depends(get_current_user)
):
    """
    Получить сообщения комнаты с пагинацией.
    
    Args:
        room_id: ID комнаты
        limit: Сколько сообщений вернуть (1-100, по умолчанию 50)
        offset: Со скольких сообщений начать считать (для пагинации)
    
    Returns:
        {
            "items": [...],
            "total": 1234,
            "limit": 50,
            "offset": 0
        }
    """
    
    # Валидация параметров
    limit = min(100, max(1, limit))  # Между 1 и 100
    offset = max(0, offset)           # Не отрицательно
    
    # 1. Проверяем, существует ли комната
    room_result = await session.execute(
        select(ChatRoom).where(ChatRoom.id == room_id)
    )
    room = room_result.scalar_one_or_none()
    
    if not room:
        raise HTTPException(status_code=404, detail="Комната не найдена")
    
    # 2. Проверяем, что пользователь в этой комнате
    member_result = await session.execute(
        select(RoomMember).where(
            (RoomMember.room_id == room_id) &
            (RoomMember.user_id == current_user.telegram_id)
        )
    )
    if not member_result.scalar_one_or_none():
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Вы не в этой комнате"
        )
    
    # 3. Получить TOTAL (сколько всего не удаленных сообщений)
    total_result = await session.execute(
        select(func.count(Message.id)).where(
            (Message.room_id == room_id) &
            (Message.is_deleted == False)
        )
    )
    total = total_result.scalar() or 0
    
    # 4. Получить сообщения с сортировкой
    # ВАЖНО: Сортируем по created_at DESC (новые в начале),
    # потом по id DESC (для дубликатов с одинаковым временем)
    messages_result = await session.execute(
        select(Message, User).join(
            User, Message.user_id == User.telegram_id
        ).where(
            (Message.room_id == room_id) &
            (Message.is_deleted == False)
        ).order_by(
            Message.created_at.desc(),  # Новые в начале
            Message.id.desc()            # Вторичная сортировка
        ).offset(offset).limit(limit)
    )
    
    messages = messages_result.all()
    
    # 5. Форматируем ответ
    items = [
        {
            "id": msg[0].id,
            "room_id": msg[0].room_id,
            "user_id": msg[0].user_id,
            "username": msg[1].username,
            "full_name": msg[1].full_name,
            "text": msg[0].text,
            "created_at": msg[0].created_at,
            "updated_at": msg[0].updated_at,
            "is_deleted": msg[0].is_deleted
        }
        for msg in messages
    ]
    
    return MessagesListResponse(
        items=items,
        total=total,
        limit=limit,
        offset=offset
    )
```

```javascript
// Состояние пагинации
const pagination = {
  currentOffset: 0,
  limit: 50,
  total: 0,
  roomId: null
};

// Загрузить сообщения
async function loadMessages(roomId, offset = 0, append = false) {
  const loadingEl = document.getElementById('loading-indicator');
  loadingEl.style.display = 'block';

  try {
    const url = `/api/rooms/${roomId}/messages?limit=${pagination.limit}&offset=${offset}`;
    
    const response = await fetch(url, {
      method: 'GET',
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('access_token')}`
      }
    });

    if (!response.ok) {
      throw new Error('Ошибка при загрузке сообщений');
    }

    const data = await response.json();
    
    // Обновляем состояние пагинации
    pagination.currentOffset = offset;
    pagination.total = data.total;
    pagination.roomId = roomId;

    // Отображаем сообщения
    displayMessages(data.items, append);
    
    // Обновляем состояние кнопок
    updatePaginationButtons();

    return data.items;
  } catch (error) {
    console.error('Ошибка:', error);
    alert('Ошибка при загрузке сообщений');
  } finally {
    loadingEl.style.display = 'none';
  }
}

// Отобразить сообщения
function displayMessages(messages, append = false) {
  const container = document.getElementById('messages-container');
  
  if (!append) {
    container.innerHTML = ''; // Очистить если не добавляем
  }

  messages.forEach(msg => {
    const messageEl = document.createElement('div');
    messageEl.className = 'message-item';
    messageEl.id = `message-${msg.id}`;
    
    // Ваш шаблон сообщения
    messageEl.innerHTML = `
      <div class="message-header">
        <strong>${msg.full_name || msg.username}</strong>
        <span class="message-time">${new Date(msg.created_at).toLocaleString()}</span>
      </div>
      <div class="message-text">${escapeHtml(msg.text)}</div>
      ${msg.updated_at ? `<div class="message-edited">(отредактировано)</div>` : ''}
    `;
    
    if (append) {
      // Добавить в конец (старые сообщения)
      container.appendChild(messageEl);
    } else {
      // Вставить в начало (новые сообщения)
      container.insertBefore(messageEl, container.firstChild);
    }
  });
}

// Обновить состояние кнопок пагинации
function updatePaginationButtons() {
  const loadOlderBtn = document.getElementById('load-older-btn');
  
  // Кнопка "Загрузить старые" видна если есть еще старые сообщения
  const nextOffset = pagination.currentOffset + pagination.limit;
  loadOlderBtn.style.display = nextOffset < pagination.total ? 'block' : 'none';
}

// "Загрузить старые сообщения"
document.getElementById('load-older-btn').addEventListener('click', async () => {
  const nextOffset = pagination.currentOffset + pagination.limit;
  await loadMessages(pagination.roomId, nextOffset, true);
});

// "Обновить чат" (вернуться к новым сообщениям)
document.getElementById('refresh-btn').addEventListener('click', async () => {
  await loadMessages(pagination.roomId, 0, false);
});

// При загрузке страницы
document.addEventListener('DOMContentLoaded', async () => {
  const roomId = getRoomIdFromUrl();
  await loadMessages(roomId, 0, false);
});

// Вспомогательные функции
function escapeHtml(unsafe) {
  return unsafe
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&#039;");
}

function getRoomIdFromUrl() {
  const pathParts = window.location.pathname.split('/');
  return parseInt(pathParts[pathParts.length - 1]);
}
```

## 🔄 ШАГ 3: REAL-TIME ОБНОВЛЕНИЕ (ОПЦИОНАЛЬНО)

Если нужна автоматическая загрузка новых сообщений:

```javascript
// Автоматически проверять новые сообщения каждые 3 секунды
let autoRefreshInterval = null;

function startAutoRefresh() {
  autoRefreshInterval = setInterval(async () => {
    // Грузим с offset=0 чтобы получить новые
    const url = `/api/rooms/${pagination.roomId}/messages?limit=${pagination.limit}&offset=0`;
    
    const response = await fetch(url, {
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('access_token')}`
      }
    });

    if (response.ok) {
      const data = await response.json();
      // Если новых сообщений больше чем было - добавляем их
      if (data.total > pagination.total) {
        displayMessages(data.items, false);
      }
    }
  }, 3000);
}

function stopAutoRefresh() {
  if (autoRefreshInterval) {
    clearInterval(autoRefreshInterval);
    autoRefreshInterval = null;
  }
}

// Запустить при загрузке страницы
document.addEventListener('DOMContentLoaded', () => {
  startAutoRefresh();
});

// Остановить при уходе со страницы
window.addEventListener('beforeunload', () => {
  stopAutoRefresh();
});
```

## ⚠️ ВАЖНО: СОРТИРОВКА

### Почему нужна вторичная сортировка?

Представьте: 1000 сообщений созданы в одно и то же время (1 миллисекунда). Если сортировать только по `created_at`:

**Запрос 1:** `limit=20, offset=0` → сообщения 1-20
**Запрос 2:** `limit=20, offset=20` → сообщения 1-20 (ДУБЛИ!)

**Решение:** Сортируем по `created_at, id` (оба DESC):

```python
.order_by(
    Message.created_at.desc(),  # Первичная: время
    Message.id.desc()            # Вторичная: ID (гарантирует уникальность)
)
```

Теперь дубликатов не будет!

## 🐛 РЕШЕНИЕ ЧАСТЫХ ПРОБЛЕМ

### Проблема: "Ошибка 422 - Validation Error"
**Причина:** limit или offset имеет неправильный тип или формат.
**Решение:** Проверить что параметры передаются как числа: `?limit=50&offset=0`

### Проблема: Одни и те же сообщения загружаются дважды
**Причина:** Вторичная сортировка по ID отсутствует.
**Решение:** Добавить `.order_by(Message.id.desc())` как вторичную.

### Проблема: "total" не совпадает с реальным количеством
**Причина:** Считаем deleted сообщения или не считаем.
**Решение:** Убедиться что используется `Message.is_deleted == False`.

### Проблема: Кнопка "Загрузить старые" не видна
**Причина:** nextOffset >= total
**Решение:** Проверить логику в `updatePaginationButtons()`.
