## 📌 ВВЕДЕНИЕ

**Что это?** Real-time показ "Пользователь печатает..." в чате.

**Зачем нужно?**
- User Experience: видно что собеседник пишет ответ
- Не грузит сервер: передаем только при вводе (debounce)
- Автоматический таймаут: статус исчезает через 5 сек если человек забыл сказать

**Текущее состояние:**
- ❌ Нет таблицы TypingStatus
- ❌ Нет API endpoints
- ❌ Нет индикации на фронтенде

**Результат после ТЗ-11:**
```
1. Пользователь А начинает печатать в чат
2. Фронтенд отправляет POST /api/rooms/1/typing каждые 3 сек
3. Пользователь Б открывает GET /api/rooms/1/typing
4. Видит: "А печатает..."
5. Если А прекратил - через 5 сек статус исчезает
```

### Создать TypingStatus таблицу

**Файл:** `backend/api/models.py`

```python
from datetime import datetime, timedelta

class TypingStatus(SQLModel, table=True):
    """
    Таблица для отслеживания, кто печатает в какой комнате.
    
    Поля:
    - user_id: ID пользователя (который печатает)
    - room_id: ID комнаты
    - updated_at: Когда последний раз пользователь обновил статус печати
    
    Логика:
    - Когда пользователь печатает: upsert TypingStatus (или обновляем updated_at)
    - Когда показываем: фильтруем по updated_at < 5 сек назад
    """
    __tablename__ = "typing_status"
    
    id: Optional[int] = Field(default=None, primary_key=True)
    user_id: str = Field(foreign_key="user.telegram_id", nullable=False)
    room_id: int = Field(foreign_key="chatroom.id", nullable=False)
    updated_at: datetime = Field(
        default_factory=lambda: datetime.utcnow() + timedelta(hours=3)
    )
    
    # Уникальное ограничение: один пользователь может печатать только один раз в комнате
    __table_args__ = (UniqueConstraint("user_id", "room_id", name="uq_typing_user_room"),)
```

### 2.1. POST /api/rooms/{id}/typing (обновить статус печати)

```python
from datetime import datetime, timedelta

@router.post("/rooms/{room_id}/typing")
async def update_typing_status(
    room_id: int,
    session: AsyncSession = Depends(get_session),
    current_user: User = Depends(get_current_user)
):
    """
    Обновить статус печати пользователя в комнате.
    
    Когда пользователь печатает → отправляем этот запрос.
    Бэкенд обновляет updated_at = текущее время.
    
    Args:
        room_id: ID комнаты
    
    Returns:
        {"status": "ok", "message": "Статус печати обновлен"}
    """
    
    # 1. Проверяем, существует ли комната
    room_result = await session.execute(
        select(ChatRoom).where(ChatRoom.id == room_id)
    )
    room = room_result.scalar_one_or_none()
    
    if not room:
        raise HTTPException(status_code=404, detail="Комната не найдена")
    
    # 2. Проверяем, что пользователь в этой комнате
    member_result = await session.execute(
        select(RoomMember).where(
            (RoomMember.room_id == room_id) &
            (RoomMember.user_id == current_user.telegram_id)
        )
    )
    if not member_result.scalar_one_or_none():
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Вы не в этой комнате"
        )
    
    # 3. Получить или создать TypingStatus
    typing_result = await session.execute(
        select(TypingStatus).where(
            (TypingStatus.user_id == current_user.telegram_id) &
            (TypingStatus.room_id == room_id)
        )
    )
    typing = typing_result.scalar_one_or_none()
    
    if typing:
        # Обновляем существующий
        typing.updated_at = datetime.utcnow() + timedelta(hours=3)
    else:
        # Создаем новый
        typing = TypingStatus(
            user_id=current_user.telegram_id,
            room_id=room_id,
            updated_at=datetime.utcnow() + timedelta(hours=3)
        )
        session.add(typing)
    
    await session.commit()
    
    return {
        "status": "ok",
        "message": "Статус печати обновлен"
    }
```

### 2.2. GET /api/rooms/{id}/typing (получить активных печатающих)

```python
class TypingStatusResponse(BaseModel):
    """Ответ для статуса печати"""
    user_id: str
    username: str
    full_name: Optional[str]
    typing_since: int  # Секунды назад когда начал печатать

class RoomTypingStatusResponse(BaseModel):
    """Ответ со списком печатающих"""
    typing_users: List[TypingStatusResponse]
    room_id: int

@router.get("/rooms/{room_id}/typing", response_model=RoomTypingStatusResponse)
async def get_typing_status(
    room_id: int,
    session: AsyncSession = Depends(get_session),
    current_user: User = Depends(get_current_user)
):
    """
    Получить список пользователей, которые сейчас печатают в комнате.
    
    Возвращает только тех, кто обновил статус менее 5 секунд назад.
    
    Args:
        room_id: ID комнаты
    
    Returns:
        {
            "typing_users": [
                {
                    "user_id": "123",
                    "username": "ivan",
                    "full_name": "Иван Петров",
                    "typing_since": 2  # 2 секунды назад
                }
            ],
            "room_id": 1
        }
    """
    
    # 1. Проверяем, существует ли комната
    room_result = await session.execute(
        select(ChatRoom).where(ChatRoom.id == room_id)
    )
    room = room_result.scalar_one_or_none()
    
    if not room:
        raise HTTPException(status_code=404, detail="Комната не найдена")
    
    # 2. Проверяем, что пользователь в этой комнате
    member_result = await session.execute(
        select(RoomMember).where(
            (RoomMember.room_id == room_id) &
            (RoomMember.user_id == current_user.telegram_id)
        )
    )
    if not member_result.scalar_one_or_none():
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Вы не в этой комнате"
        )
    
    # 3. Получить активных печатающих (обновили <= 5 сек назад)
    now = datetime.utcnow() + timedelta(hours=3)
    cutoff_time = now - timedelta(seconds=5)
    
    typing_result = await session.execute(
        select(TypingStatus, User).join(
            User, TypingStatus.user_id == User.telegram_id
        ).where(
            (TypingStatus.room_id == room_id) &
            (TypingStatus.updated_at > cutoff_time)  # Обновлено менее 5 сек назад
        )
    )
    
    typing_entries = typing_result.all()
    
    typing_users = []
    for typing, user in typing_entries:
        # Не показываем самого себя в списке печатающих
        if user.telegram_id != current_user.telegram_id:
            seconds_ago = int((now - typing.updated_at).total_seconds())
            typing_users.append(
                TypingStatusResponse(
                    user_id=user.telegram_id,
                    username=user.username,
                    full_name=user.full_name,
                    typing_since=seconds_ago
                )
            )
    
    return RoomTypingStatusResponse(
        typing_users=typing_users,
        room_id=room_id
    )
```

### JavaScript (в room.js):

```javascript
// Состояние печати
const typingState = {
  typingInputTimeout: null,      // Таймер debounce
  typingPollInterval: null,      // Таймер для GET /typing
  lastTypingUpdate: 0,           // Когда последний раз отправили POST
  isCurrentlyTyping: false,      // Печатаем ли мы сейчас
  roomId: null
};

// ЧАСТЬ 1: Отправлять POST /typing при вводе (debounce)
function setupTypingListener() {
  const inputField = document.getElementById('message-input');
  
  if (!inputField) return;
  
  inputField.addEventListener('input', () => {
    // Помечаем что печатаем
    typingState.isCurrentlyTyping = true;
    
    // Очищаем старый таймер
    clearTimeout(typingState.typingInputTimeout);
    
    // Отправляем статус если прошло > 3 сек
    const now = Date.now();
    if (now - typingState.lastTypingUpdate > 3000) {
      sendTypingStatus();
      typingState.lastTypingUpdate = now;
    }
    
    // Таймер: если не печатал 5 сек - помечаем что не печатаем
    typingState.typingInputTimeout = setTimeout(() => {
      typingState.isCurrentlyTyping = false;
    }, 5000);
  });
  
  // При фокусировании на инпут - начать слушать печать
  inputField.addEventListener('focus', () => {
    startTypingPolling();
  });
}

// Отправить POST /typing
async function sendTypingStatus() {
  if (!typingState.roomId) return;
  
  try {
    const response = await fetch(
      `/api/rooms/${typingState.roomId}/typing`,
      {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${localStorage.getItem('access_token')}`
        }
      }
    );
    
    if (!response.ok) {
      console.warn('Не удалось отправить статус печати');
    }
  } catch (error) {
    console.error('Ошибка отправки печати:', error);
  }
}

// ЧАСТЬ 2: Опрашивать GET /typing каждую секунду
function startTypingPolling() {
  if (typingState.typingPollInterval) {
    return; // Уже опрашиваем
  }
  
  typingState.typingPollInterval = setInterval(() => {
    fetchTypingStatus();
  }, 1000); // Проверяем каждую секунду
}

function stopTypingPolling() {
  if (typingState.typingPollInterval) {
    clearInterval(typingState.typingPollInterval);
    typingState.typingPollInterval = null;
  }
}

// Получить и показать статус печати
async function fetchTypingStatus() {
  if (!typingState.roomId) return;
  
  try {
    const response = await fetch(
      `/api/rooms/${typingState.roomId}/typing`,
      {
        method: 'GET',
        headers: {
          'Authorization': `Bearer ${localStorage.getItem('access_token')}`
        }
      }
    );
    
    if (!response.ok) return;
    
    const data = await response.json();
    displayTypingIndicator(data.typing_users);
  } catch (error) {
    console.error('Ошибка получения статуса печати:', error);
  }
}

// Показать/скрыть индикатор печати
function displayTypingIndicator(typingUsers) {
  const typingIndicator = document.getElementById('typing-indicator');
  const typingUsersList = document.getElementById('typing-users-list');
  const typingEnding = document.getElementById('typing-ending');
  
  if (typingUsers.length === 0) {
    // Никто не печатает
    typingIndicator.style.display = 'none';
    return;
  }
  
  // Формируем список имен
  const names = typingUsers.map(u => u.full_name || u.username);
  const userList = names.join(', ');
  
  // Правильное окончание
  if (typingUsers.length === 1) {
    typingEnding.textContent = 'ит';
  } else if (typingUsers.length === 2) {
    typingEnding.textContent = 'ят';
  } else {
    typingEnding.textContent = 'ят';
  }
  
  typingUsersList.textContent = userList;
  typingIndicator.style.display = 'block';
}

// Инициализация при загрузке страницы
document.addEventListener('DOMContentLoaded', () => {
  typingState.roomId = getRoomIdFromUrl();
  setupTypingListener();
});

// Очистка при уходе со страницы
window.addEventListener('beforeunload', () => {
  stopTypingPolling();
  clearTimeout(typingState.typingInputTimeout);
});

// Очистка при скрытии вкладки
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    stopTypingPolling();
  } else {
    startTypingPolling();
  }
});
```

## 🐛 РЕШЕНИЕ ЧАСТЫХ ПРОБЛЕМ

### Проблема: "Индикатор никогда не появляется"
**Причина:** GET /typing не опрашивается или пользователь не имеет доступ к комнате.
**Решение:** 
- Проверить что оба пользователя в одной комнате
- Проверить что startTypingPolling() вызывается
- Проверить консоль браузера на ошибки

### Проблема: "Индикатор исчезает слишком рано (не 5 сек)"
**Причина:** Таймер на фронтенде (`typingState.typingInputTimeout = 5000`) не совпадает с бэком (5 сек).
**Решение:** Убедиться что обе стороны используют 5 сек.

### Проблема: "Один пользователь видит себя в списке печатающих"
**Причина:** Фильтр `if (user.telegram_id != current_user.telegram_id)` не работает.
**Решение:** Проверить что в ответе у пользователя правильный telegram_id.

### Проблема: "После POST /typing видны старые записи (старше 5 сек)"
**Причина:** Условие `updated_at > cutoff_time` не работает правильно.
**Решение:** Проверить что время на сервере правильное.

### Проблема: "Не удалось отправить статус печати" в консоли
**Причина:** 
1. Токен истек
2. Пользователь не в комнате
3. Комната не существует

**Решение:** Добавить логирование:
```javascript
console.log('Отправляем печать в комнату:', typingState.roomId);
// После ответа:
console.log('Статус:', response.status, response.statusText);
```

## ⚠️ ВАЖНЫЕ МОМЕНТЫ

### 1. Debounce vs Throttle

```javascript
// ДА (debounce) - ждем пока пользователь перестанет печатать:
clearTimeout(typingState.typingInputTimeout);
typingState.typingInputTimeout = setTimeout(() => {
  typingState.isCurrentlyTyping = false;
}, 5000);

// НЕТ (setInterval без очистки) - давит на сервер:
setInterval(() => { sendTypingStatus(); }, 1000); // Без очистки! ❌
```

### 2. Таймаут бэкенда

На бэкенде мы **никогда** не удаляем старые TypingStatus! Только читаем их если `updated_at > 5 сек назад`.

```python
# Сохраняем ВСЕ записи
typing = TypingStatus(...) # ❌ Не удаляем! 
session.add(typing)
await session.commit()

# Фильтруем только при чтении
cutoff_time = now - timedelta(seconds=5)
.where(TypingStatus.updated_at > cutoff_time)  # ✅
```

### 3. Очистка при уходе

```javascript
// ✅ ПРАВИЛЬНО - очищаем все таймеры
window.addEventListener('beforeunload', () => {
  clearTimeout(typingState.typingInputTimeout);
  clearInterval(typingState.typingPollInterval);
});

// ❌ НЕПРАВИЛЬНО - таймеры продолжают работать в фоне
// (если не очистить - браузер может зависнуть)
```
