Урок 2. Эпилог (JavaScript) — Оживляем интерфейс чата

Для этого нам понадобится JavaScript (JS) — язык, который работает прямо в твоём браузере (Chrome, Firefox, Safari). Если HTML — это "скелет" страницы, а CSS — её "одежда", то JavaScript — это "мозг и мышцы", которые заставляют её двигаться, реагировать на нажатия кнопок и показывать новую информацию без перезагрузки.
В этом уроке мы сосредоточимся на том, как с помощью JS управлять видимой частью нашего чата.
1.	DOM (Document Object Model): Это представление нашей HTML-страницы в виде дерева объектов. JavaScript может "достучаться" до любого элемента (кнопки, поля ввода, блока для сообщений) и изменить его: добавить текст, поменять цвет, скрыть или показать.
2.	События (Events): Как JS узнает, что пользователь что-то сделал? Он "слушает" события: клик мыши, нажатие клавиши, отправку формы. Мы научимся реагировать на эти события.
3.	Переменные и Типы Данных: Как и в Python, мы будем хранить данные (имя пользователя, список сообщений) в переменных, списках (здесь они называются массивами — Array) и словарях (здесь они называются объектами — Object).
4.	Функции: Мы будем группировать наш код в функции, чтобы выполнять определённые действия, например, displayNewMessage() (отобразить новое сообщение) или updateUserList() (обновить список пользователей).
Почему это важно?
В реальном проекте "Мессенджер" именно JavaScript будет отвечать за:
•	Отображение сообщений, которые приходят от сервера.
•	Отправку на сервер того, что пользователь напечатал в поле ввода.
•	Обновление списка пользователей онлайн.
•	Отображение уведомлений и статусов.

Циклы: Перебор элементов
Как и в Python, в JS есть несколько способов перебрать элементы.
Цикл for...of (Аналог for ... in ... в Python)
Используется для перебора значений в массивах.
const fruits = ['яблоко', 'банан', 'вишня'];

for (const fruit of fruits) {
  console.log(fruit);
}

Цикл for со счетчиком (Классический цикл)
Нужен, когда важен порядковый номер (индекс) элемента.
const numbers = [10, 20, 30, 40];

for (let i = 0; i < numbers.length; i++) {
  console.log(`Элемент с индексом ${i} равен ${numbers[i]}`);
}
Обрати внимание:
 let i = 0;       - создаем счетчик
i < numbers.length; - условие продолжения цикла (аналог len() в Python)
 i++             - увеличиваем счетчик на 1 после каждого шага

Теперь, вооружившись этими базовыми знаниями, мы готовы приступить к созданию нашего умного клиента для чата
Слово const (от английского constant — постоянный, неизменяемый) используется для объявления константы.
Что означает const?
Когда вы объявляете переменную с помощью const, вы говорите JavaScript две вещи:
1.	Создать новую переменную.
2.	Присвоить ей значение, которое НЕ МОЖЕТ быть изменено (переприсвоено) позже.
Попробуйте запустить этот код, чтобы увидеть ошибку:
const PI = 3.14159;
console.log(PI); // 3.14159

// PI = 3.14; // Если раскомментировать эту строку, вы получите ошибку!
             // Uncaught TypeError: Assignment to constant variable.
Зачем мы используем const?
Вы абсолютно правы, без const код работать будет, если вместо него использовать let или (старый) var. Но const имеет несколько важных преимуществ:
1.	Надежность и предсказуемость:
•	Когда вы видите const, вы сразу понимаете: значение этой переменной не изменится. Это значительно упрощает чтение и понимание кода.
•	Это помогает избежать случайных ошибок, когда вы по невнимательности переприсваиваете значение важной переменной. JS "поймает" эту ошибку за вас.
2.	Лучшая оптимизация:
•	JavaScript-движки (программы, которые выполняют JS-код) могут иногда оптимизировать код, где используются константы, так как знают, что их значение стабильно.
3.	Безопасность:
•	В случае, когда переменная должна хранить ссылку на DOM-элемент (например, chatWindow), объект, или функцию, и вы не ожидаете, что эта ссылка будет меняться, const — идеальный выбор.
А если нужно, чтобы значение менялось?
Для этого есть ключевое слово let (от английского let — позволить, дать).
let userName = "Алиса";
console.log(userName); // Алиса

userName = "Боб"; // Здесь мы можем переприсвоить значение
console.log(userName); // Боб

Мы используем let тогда, когда знаем, что значение переменной будет меняться в течение работы программы (например, счетчик в цикле, статус пользователя, текущее значение в поле ввода).
•	const используйте всегда, когда вы уверены, что значение переменной не будет меняться (или если вы храните ссылку на объект/массив, который может меняться внутри, но сама ссылка на него — нет).
•	let используйте, когда вы знаете, что значение переменной будет или может быть изменено.
•	var старайтесь не использовать вовсе в современном JavaScript.
В нашем уроке мы часто используем const, потому что DOM-элементы (chatWindow, userList), формы (messageForm) и функции, которые мы к ним привязываем, обычно не меняют своей ссылки на протяжении работы приложения.
