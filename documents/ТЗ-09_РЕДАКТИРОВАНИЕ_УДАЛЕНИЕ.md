**Что это?** CRUD операции для сообщений с проверкой прав доступа.

**Зачем нужно?**
- Пользователи могут исправлять опечатки в своих сообщениях
- Пользователи могут удалять свои сообщения
- Никто не может менять чужие сообщения (безопасность)

**Текущее состояние:**

- ❌ Нет PATCH эндпоинта для редактирования

## 🎯 АРХИТЕКТУРА РЕШЕНИЯ

### Безопасность:
```
Запрос PATCH/DELETE /api/messages/{id}
    ↓
1. Проверить: сообщение существует? (404)
2. Проверить: current_user.id == message.author_id? (403)
3. Проверить: не меняет ли user_id, room_id? 
4. Выполнить операцию
```

### HTTP методы:
- `PATCH /api/messages/{id}` — обновить (частичное изменение)
- `DELETE /api/messages/{id}` — удалить

### Почему эти поля нужны?
- **`updated_at`** — показать пользователю "отредактировано в X времени"
- **`is_deleted`** — мягкое удаление (история остается, но сообщение не видно)

**Добавить функцию:**

```python
from fastapi import HTTPException, status

@router.patch("/messages/{message_id}", response_model=MessageResponse)
async def update_message(
    message_id: int,
    update_req: UpdateMessageRequest,
    session: AsyncSession = Depends(get_session),
    current_user: User = Depends(get_current_user)
):
    """
    Редактировать сообщение.
    
    Проверяет:
    1. Сообщение существует
    2. Текущий пользователь - автор сообщения
    3. Сообщение не удалено
    
    Args:
        message_id: ID сообщения
        update_req: {"text": "Новый текст"}
    
    Returns:
        Обновленное сообщение
    """
    
    # 1. Получить сообщение
    msg_result = await session.execute(
        select(Message).where(Message.id == message_id)
    )
    message = msg_result.scalar_one_or_none()
    
    if not message:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Сообщение не найдено"
        )
    
    # 2. Проверить, что это сообщение текущего пользователя
    if message.user_id != current_user.telegram_id:
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Вы не можете редактировать чужие сообщения"
        )
    
    # 3. Проверить, не удалено ли сообщение
    if message.is_deleted:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="Это сообщение было удалено"
        )
    
    # 4. Обновить текст и время редактирования
    message.text = update_req.text
    message.updated_at = datetime.now(timezone.utc) + timedelta(hours=3)
    
    session.add(message)
    await session.commit()
    await session.refresh(message)
    
    return message
```

```python
@router.delete("/messages/{message_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_message(
    message_id: int,
    session: AsyncSession = Depends(get_session),
    current_user: User = Depends(get_current_user)
):
    """
    Удалить сообщение (мягкое удаление).
    
    Проверяет:
    1. Сообщение существует
    2. Текущий пользователь - автор сообщения
    
    Args:
        message_id: ID сообщения
    
    Returns:
        204 No Content (без тела)
    """
    
    # 1. Получить сообщение
    msg_result = await session.execute(
        select(Message).where(Message.id == message_id)
    )
    message = msg_result.scalar_one_or_none()
    
    if not message:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Сообщение не найдено"
        )
    
    # 2. Проверить, что это сообщение текущего пользователя
    if message.user_id != current_user.telegram_id:
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Вы не можете удалить чужое сообщение"
        )
    
    # 3. Мягкое удаление (помечаем как удаленное)
    message.is_deleted = True
    message.updated_at = datetime.now(timezone.utc) + timedelta(hours=3)
    
    session.add(message)
    await session.commit()
    
    # Возвращаем 204 (No Content)
```

```python
@router.get("/rooms/{room_id}/messages")
async def get_messages(room_id: int, ...):
    result = await session.execute(
        select(Message).where(Message.room_id == room_id)
    )
    return result.scalars().all()

# ПОСЛЕ (правильно - фильтруем is_deleted):
@router.get("/rooms/{room_id}/messages")
async def get_messages(room_id: int, ...):
    result = await session.execute(
        select(Message).where(
            (Message.room_id == room_id) & 
            (Message.is_deleted == False)  # Важно!
        )
    )
    return result.scalars().all()
```

```javascript
let editingMessageId = null; // Какое сообщение редактируем

// Отобразить сообщения
function displayMessages(messages, currentUserId) {
  const container = document.getElementById('messages-container');
  container.innerHTML = '';

  messages.forEach(msg => {
    const messageEl = document.createElement('div');
    messageEl.className = 'message-item';
    
    // Проверяем, это наше сообщение?
    const isOwn = msg.user_id === currentUserId;
    
    // Форматируем время
    const createdTime = new Date(msg.created_at).toLocaleString();
    const editedTime = msg.updated_at ? new Date(msg.updated_at).toLocaleString() : null;
    
    // HTML сообщения
    messageEl.innerHTML = `
      <div class="message-header">
        <strong>${msg.username}</strong>
        <span class="message-time">${createdTime}</span>
      </div>
      <div class="message-text">${escapeHtml(msg.text)}</div>
      ${editedTime ? `<div class="message-edited">(отредактировано ${editedTime})</div>` : ''}
      ${isOwn ? `
        <div class="message-actions">
          <button class="btn-edit" data-id="${msg.id}">Редактировать</button>
          <button class="btn-delete" data-id="${msg.id}">Удалить</button>
        </div>
      ` : ''}
    `;
    
    container.appendChild(messageEl);
  });

  // Добавить обработчики на кнопки редактирования/удаления
  document.querySelectorAll('.btn-edit').forEach(btn => {
    btn.addEventListener('click', openEditModal);
  });

  document.querySelectorAll('.btn-delete').forEach(btn => {
    btn.addEventListener('click', deleteMessage);
  });
}

// Открыть модаль редактирования
function openEditModal(event) {
  const messageId = parseInt(event.target.dataset.id);
  
  // Найти сообщение в DOM
  const messageEl = event.target.closest('.message-item');
  const messageText = messageEl.querySelector('.message-text').textContent;
  
  editingMessageId = messageId;
  document.getElementById('edit-message-text').value = messageText;
  document.getElementById('edit-modal').style.display = 'block';
  document.getElementById('edit-message-text').focus();
}

// Закрыть модаль
document.querySelector('#edit-modal .close').addEventListener('click', () => {
  document.getElementById('edit-modal').style.display = 'none';
  editingMessageId = null;
});

document.getElementById('edit-cancel-btn').addEventListener('click', () => {
  document.getElementById('edit-modal').style.display = 'none';
  editingMessageId = null;
});

// Сохранить редактирование
document.getElementById('edit-confirm-btn').addEventListener('click', async () => {
  const newText = document.getElementById('edit-message-text').value.trim();

  if (!newText) {
    alert('Текст не может быть пустым');
    return;
  }

  try {
    const response = await fetch(`/api/messages/${editingMessageId}`, {
      method: 'PATCH',
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('access_token')}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ text: newText })
    });

    if (!response.ok) {
      const error = await response.json();
      alert(`Ошибка: ${error.detail}`);
      return;
    }

    alert('Сообщение успешно отредактировано');
    document.getElementById('edit-modal').style.display = 'none';
    editingMessageId = null;
    
    // Перезагрузить сообщения
    const roomId = getRoomIdFromUrl();

    console.error('Ошибка:', error);
    alert('Ошибка при редактировании сообщения');
  }

// Удалить сообщение
async function deleteMessage(event) {
  const messageId = parseInt(event.target.dataset.id);

  if (!confirm('Вы уверены? Это действие нельзя отменить.')) {
    return;
  }

  try {
    const response = await fetch(`/api/messages/${messageId}`, {
      method: 'DELETE',
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('access_token')}`
      }
    });

    if (!response.ok) {
      const error = await response.json();
      alert(`Ошибка: ${error.detail}`);
      return;
    }

    alert('Сообщение успешно удалено');
    
    // Перезагрузить сообщения
    const roomId = getRoomIdFromUrl();
    loadMessages(roomId);
  } catch (error) {
    console.error('Ошибка:', error);
    alert('Ошибка при удалении сообщения');
  }
}

// Вспомогательная функция для экранирования HTML
function escapeHtml(unsafe) {
  return unsafe
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&#039;");
}

// Получить ID комнаты
function getRoomIdFromUrl() {
  const pathParts = window.location.pathname.split('/');
  return parseInt(pathParts[pathParts.length - 1]);
}

// При загрузке страницы

  const currentUser = await getCurrentUser(); // получить текущего пользователя
  const messages = await loadMessages(roomId);
  displayMessages(messages, currentUser.telegram_id);
});
```

## 🐛 РЕШЕНИЕ ЧАСТЫХ ПРОБЛЕМ

### Проблема: "Сообщение не найдено" при редактировании своего сообщения
**Причина:** ID сообщения неправильный или сообщение удалено.
**Решение:** Проверить ID в URL, убедиться что сообщение существует в БД.

### Проблема: 403 Forbidden при редактировании своего сообщения
**Причина:** `user_id` в БД не совпадает с `current_user.telegram_id`.
**Решение:** Проверить, правильно ли сохраняется user_id при создании сообщения.

### Проблема: Кнопки редактирования/удаления не видны
**Причина:** `current_user.telegram_id` не совпадает с `msg.user_id` или фронтенд ошибка.
**Решение:** Добавить `console.log()` для отладки значений.

### Проблема: "Это сообщение было удалено" при попытке редактирования
**Причина:** Проверка `is_deleted` срабатывает.
**Решение:** Либо восстановить сообщение (удалить запись), либо создать новое.
