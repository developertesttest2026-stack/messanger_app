🌐 Теоретический модуль: Как  общается с сервером
В веб-разработке клиент (браузер) и сервер обмениваются данными.  может отправлять запросы и получать ответы без перезагрузки страницы. Главный инструмент для этого — встроенная функция fetch. Мы разберём, как:
•	отправлять GET запросы и читать JSON ответы;
•	отправлять данные на сервер методами POST, PATCH, DELETE;
•	работать с async/await, чтобы код не блокировал интерфейс;
•	преобразовывать объекты в JSON и обратно;
•	обрабатывать ошибки (нет сети, 404, 500);
•	использовать базовые методы массивов и объектов для данных от сервера.

1. Что такое fetch и как сделать GET запрос
fetch(url) — функция, которая отправляет запрос на сервер и возвращает обещание (Promise). Чтобы дождаться ответа, используют await или .then(). Мы будем использовать async/await — это современно и понятно.

async function getWeather() {
  try {
    const response = await fetch('https://api.example.com/weather');
    if (!response.ok) {
      throw new Error(`Ошибка HTTP: ${response.status}`);
    }
    const data = await response.json();
    console.log('Температура:', data.temperature);
  } catch (error) {
    console.error('Не удалось получить погоду:', error);
  }
}

По шагам:
1.	fetch(url) — начинает запрос.
2.	await — ждёт ответа от сервера, не блокируя остальной код.
3.	response.ok — проверяет, что статус ответа 200–299.
4.	response.json() — читает тело ответа как JSON (тоже асинхронно).
5.	try...catch — ловит любые ошибки (нет интернета, сервер не отвечает, ошибка парсинга).
🧠 Важно: Сервер обычно возвращает данные в формате JSON. Это текст, который выглядит как массив или объект. response.json() превращает его в настоящий объект .

2. Отправка данных: POST запрос
Когда нужно создать что то новое (добавить запись, отправить форму), используют метод POST.

async function addBook(bookTitle, author) {
  const newBook = {
    title: bookTitle,
    author: author,
    read: false
  };

  const response = await fetch('https://api.example.com/books', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(newBook)
  });

  if (response.ok) {
    const createdBook = await response.json();
    console.log('Книга добавлена:', createdBook);
  }
}

Что здесь нового:
•	method: 'POST' — явно указываем тип запроса.
•	headers — сообщаем серверу, что отправляем JSON.
•	body — данные, преобразованные в строку через JSON.stringify().
•	Сервер обычно возвращает созданный объект (с присвоенным ID, датой и т.д.).

3. Редактирование и удаление: PATCH и DELETE
Чтобы частично изменить существующий ресурс, используют PATCH. Для удаления — DELETE.

// Обновить только поле read
async function markAsRead(bookId) {
  const response = await fetch(`https://api.example.com/books/${bookId}`, {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ read: true })
  });
  if (response.ok) {
    console.log('Статус обновлён');
  }
}

// Удалить книгу
async function deleteBook(bookId) {
  const response = await fetch(`https://api.example.com/books/${bookId}`, {
    method: 'DELETE'
  });
  if (response.status === 204) { // 204 No Content – успех без тела
    console.log('Книга удалена');
  }
}

Заметка: Для DELETE обычно не нужен body. Успех часто обозначается статусом 204.

4. Преобразование JSON ↔ 
Два главных метода:
•	JSON.stringify(объект) → JSON строка
•	JSON.parse(строка) → объект (но внутри response.json() это уже сделано)

const animal = { type: 'cat', name: 'Мурка', age: 3 };
const jsonString = JSON.stringify(animal);
console.log(jsonString); // {"type":"cat","name":"Мурка","age":3}

const parsed = JSON.parse(jsonString);

console.log(parsed.name); // Мурка
Практически всегда вы будете использовать JSON.stringify для отправки и response.json() для получения.

5. Асинхронность простыми словами
Когда браузер отправляет запрос на сервер, он не должен «замерзать» в ожидании ответа. Иначе страница перестанет реагировать на клики. async/await позволяет писать код, который выглядит последовательным, но не блокирует главный поток.

console.log('1. Начинаю запрос');
const data = await fetch('/some-data');
console.log('2. Запрос завершён');
console.log('3. Я выполнюсь после 2');
Без await пришлось бы использовать цепочку .then():

fetch('/some-data')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

Мы будем использовать async/await — так код чище.

6. Обработка ошибок: не только try/catch
Сервер может вернуть ошибку 404 (не найдено) или 500 (внутренняя ошибка). Нужно корректно реагировать.



async function safeLoadData(url) {
  try {
    const res = await fetch(url);
    if (!res.ok) {
      // Сервер ответил, но не 2xx
      throw new Error(`Ошибка ${res.status}: ${res.statusText}`);
    }
    return await res.json();
  } catch (err) {
    // Ошибка сети или наша ошибка выше
    console.error('Не удалось загрузить данные:', err.message);
    return null; // или показать уведомление пользователю
  }
}

Всегда проверяйте response.ok! Даже если сервер доступен, он может вернуть 404 или 500.

7. Работа с массивами и объектами – данные от сервера
API часто возвращает массив объектов. С ними нужно уметь делать основные операции.
Перебор (forEach) – для отрисовки списка:

const products = [

products.forEach(product => {

Фильтрация (filter) – выбрать товары дешевле 500 ₽:

const cheap = products.filter(p => p.price < 500);

Поиск (find) – найти товар по id:

Преобразование (map) – получить массив названий:

Подсчёт статистики с объектом – например, сколько товаров каждой ценовой категории:

const stats = {};
products.forEach(p => {

11. Универсальная функция для запросов
Чтобы не дублировать код, можно создать обёртку.

async function apiRequest(url, method = 'GET', body = null) {
  const options = {
    method,
    headers: { 'Content-Type': 'application/json' }
  };
  if (body) {
    options.body = JSON.stringify(body);
  }

  const response = await fetch(url, options);
  if (!response.ok) {
    throw new Error(`Ошибка ${response.status}: ${response.statusText}`);
  }

  // DELETE может не возвращать тело
  if (method === 'DELETE') return true;
  return await response.json();
}

// Примеры вызова
const allProducts = await apiRequest('/products');
const newProduct = await apiRequest('/products', 'POST', { name: 'Книга', price: 500 });
await apiRequest('/products/42', 'DELETE');

🧭 Часть А: Почему время — это сложно? (Объяснение для детей)
Представь: в время — это количество миллисекунд с 1970 года. А в Python — это специальный объект datetime. Как перевести один язык в другой? 🤔
📊 Таблица-шпаргалка: Время в ↔ Время в Python
Действие	В (клиент)	В Python (сервер)	Как преобразовать
Получить текущее время	Date.now() → 1715000000000 (мс)	datetime.now() → объект	→ : разделить на 1000
Отправить время на сервер	new Date(timestamp).toISOString() → "2024-05-06T12:00:00.000Z"	datetime.fromisoformat()	Использовать ISO-строку — универсальный язык!
Получить время от сервера	Сервер шлёт "2024-05-06T12:00:00"	datetime.isoformat()	new Date(serverTime) — поймёт!
Сравнить время	if (msgTime > lastTime)	if (msg.timestamp > since)	Привести к одному формату: лучше всего — таймстамп в мс
🎯 Золотое правило:
Всегда передавай время в формате ISO 8601 ("2024-05-06T12:00:00.000Z"). Это как эсперанто для времени — понимают все языки! 🌍

let lastMessageTimestamp = null;

// При первой загрузке сообщений — запоминаем время самого нового
async function loadMessages() {
  try {
    const response = await fetch('http://127.0.0.1:8000/messages');
    const messages = await response.json();
    
    if (messages.length > 0) {
      // Находим самое новое сообщение и сохраняем его время
      const latest = messages.reduce((latest, msg) => 
        new Date(msg.timestamp) > new Date(latest.timestamp) ? msg : latest
      );
      lastMessageTimestamp = new Date(latest.timestamp).toISOString();
    }
    
    renderMessages(messages);
  } catch (error) {
    console.error('Ошибка загрузки сообщений:', error);
  }
}

async function loadNewMessages() {
  // Если ещё не было сообщений — нечего поллить
  if (!lastMessageTimestamp) return;
  
  try {
    // 🕰️ Отправляем время в формате ISO — сервер поймёт!
    const url = `http://127.0.0.1:8000/messages/poll?since=${encodeURIComponent(lastMessageTimestamp)}`;
    const response = await fetch(url);
    
    if (!response.ok) return; // Игнорируем ошибки, чтобы не спамить консоль
    
    const newMessages = await response.json();
    
    if (newMessages.length > 0) {
      // 🎉 Новые сообщения есть! Добавляем их по одному
      for (const msg of newMessages) {
        renderSingleMessage(msg);
        
        // Обновляем "границу" времени, если это сообщение новее
        const msgTime = new Date(msg.timestamp);
        const lastTime = new Date(lastMessageTimestamp);
        if (msgTime > lastTime) {
          lastMessageTimestamp = msg.timestamp; // Сервер уже вернул в нужном формате!
        }
      }

}

// Отправь серию сообщений с задержкой
async function spamTest() {
  const bots = ["Робот-1", "Робот-2", "Робот-3"];
  for (let i = 0; i < 5; i++) {
    const randomBot = bots[Math.floor(Math.random() * bots.length)];
    sendTestMessage(randomBot, `Сообщение #${i + 1} 🤖`);
    await new Promise(resolve => setTimeout(resolve, 1000)); // Ждём 1 секунду
  }
}
