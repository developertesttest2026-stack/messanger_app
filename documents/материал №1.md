Представь, что ты — это сервер, а твои друзья — клиенты. Как ты будешь помнить, кто что сказал? Как ты отправишь сообщение всем? Именно эти вопросы мы будем решать с помощью алгоритмов — пошаговых инструкций, которые компьютер может выполнить.
В этом уроке мы сосредоточимся на Python — нашем "языке" для написания этих инструкций. Мы будем использовать базовые элементы Python, которые помогут нам "имитировать" работу чата, не вдаваясь пока в сложности сетевых технологий.
1.	Переменные и Типы Данных: Как компьютеры хранят информацию? Числа, текст (строки), списки (последовательности) и словари (пары "ключ-значение").
2.	Условные Операторы (if/else): Как компьютер принимает решения? "Если это так, сделай одно, иначе — другое".
3.	Циклы (for/while): Как компьютер повторяет действия? "Сделай это для каждого элемента" или "Делай это, пока условие истинно".
4.	Функции: Как мы организуем код, чтобы он был понятным и многоразовым? "Собери эти шаги в одну 'команду'".
5.	Списки (list) и Словари (dict): Эти структуры данных — наши главные помощники для хранения списка пользователей, истории сообщений и другой важной информации, точно так же, как мы это будем делать в реальном чате.
Почему это важно?
В уроках по чату мы будем работать с множеством сообщений, пользователей и состояний. Понимание того, как с помощью простых алгоритмов управлять этими данными, — это ключ к успешному освоению более сложных тем, таких как WebSockets, которые ждут нас впереди!

✅ Задача 12: Управление статусами пользователей
Цель: Позволить пользователям менять свой статус и уведомлять об этом.
Пример 12.1: Алиса меняет статус на "away"
python
user_data = {
    "Алиса": {"room": "general", "status": "online"},
    "Боб": {"room": "general", "status": "online"}
}
chat_rooms = {'general': ['Алиса', 'Боб']}
def change_status(nickname, new_status):
    if nickname in user_data:
        old_status = user_data[nickname]["status"]
        user_data[nickname]["status"] = new_status
        room = user_data[nickname]["room"]
        # Имитация рассылки системного сообщения
        for user in chat_rooms.get(room, []):

import uuid
chat_history = {"general": []}
chat_rooms = {"general": ["Алиса", "Боб"]}
def add_message_to_history(room_name, sender, message):
    message_id = str(uuid.uuid4())[:8] # Сокращаем ID для читаемости
    chat_history[room_name].append({"id": message_id, "sender": sender, "message": message})
    return message_id
def send_system_message_to_room(room_name, sys_message):
    for user in chat_rooms.get(room_name, []):
        print(f"[{user}] получил в [{room_name}]: Система: {sys_message}")

    if room_name not in chat_history:
        print(f"Комната '{room_name}' не найдена.")
        return
    for msg in chat_history[room_name]:
        if msg["id"] == message_id:
            if msg["sender"] == editor_nickname:
                msg["message"] = new_text
                send_system_message_to_room(room_name, f"{editor_nickname} отредактировал сообщение {message_id}.")
                return True
            else:
                print(f"[{editor_nickname}]: Вы не можете редактировать чужие сообщения.")
                return False
    print(f"Сообщение с ID {message_id} не найдено в комнате {room_name}.")
    return False
def delete_message(room_name, message_id, deleter_nickname):
    if room_name not in chat_history:
        print(f"Комната '{room_name}' не найдена.")
        return False
    for i, msg in enumerate(chat_history[room_name]):
        if msg["id"] == message_id:
            if msg["sender"] == deleter_nickname:
                del chat_history[room_name][i]
                send_system_message_to_room(room_name, f"{deleter_nickname} удалил сообщение {message_id}.")
                return True
            else:
                print(f"[{deleter_nickname}]: Вы не можете удалять чужие сообщения.")
                return False
    print(f"Сообщение с ID {message_id} не найдено в комнате {room_name}.")
    return False
