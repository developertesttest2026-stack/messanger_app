## 📌 ВВЕДЕНИЕ

**Что это?** Система управления участниками комнаты с возможностью приглашать новых пользователей.

**Зачем нужно?** 
- Контролировать кто может читать/писать в комнате
- Администратору приглашать людей
- Предотвращать дубли (один пользователь не может быть добавлен дважды в одну комнату)

**Текущее состояние:**
- ✅ Таблица `RoomMember` существует
- ❌ Нет проверки уникальности (room_id, user_id)
- ❌ Нет API для приглашений
- ❌ Нет фронтенда для приглашений

## 🔍 ШАГ 1: ОБНОВЛЕНИЕ МОДЕЛИ (BACKEND)

### Проблема:
В таблице `RoomMember` сейчас НЕТ ограничения, что один пользователь не может быть добавлен дважды в одну комнату. Можно создать дубли!

### Решение:
Добавить `UniqueConstraint` для пары (room_id, user_id).

**Файл:** `backend/api/models.py`

**Текущий код:**
```python
class RoomMember(SQLModel, table=True):
    __tablename__ = "room_members"

    id: Optional[int] = Field(default=None, primary_key=True)
    room_id: int = Field(foreign_key="chat_rooms.id", nullable=False)
    user_id: int = Field(foreign_key="users.telegram_id", nullable=False)
    joined_at: Optional[datetime] = Field(default_factory=lambda: datetime.now(timezone.utc) + timedelta(hours=3))
```

**Обновленный код:**
```python
from sqlalchemy import UniqueConstraint

class RoomMember(SQLModel, table=True):
    __tablename__ = "room_members"

    id: Optional[int] = Field(default=None, primary_key=True)
    room_id: int = Field(foreign_key="chat_rooms.id", nullable=False)
    user_id: int = Field(foreign_key="users.telegram_id", nullable=False)
    joined_at: Optional[datetime] = Field(default_factory=lambda: datetime.now(timezone.utc) + timedelta(hours=3))
    
    # ДОБАВЛЯЕМ ОГРАНИЧЕНИЕ УНИКАЛЬНОСТИ
    __table_args__ = (
        UniqueConstraint("room_id", "user_id", name="unique_room_user"),
    )
```

### Что произойдет?
При попытке добавить одного и того же пользователя дважды в комнату БД выдаст ошибку:
```
IntegrityError: UNIQUE constraint failed: room_members.room_id, room_members.user_id
```

## 🛣️ ШАГ 2: API ENDPOINT - ПОЛУЧИТЬ УЧАСТНИКОВ

### Что нужно?
Эндпоинт для получения списка участников комнаты.

**Endpoint:** `GET /api/rooms/{room_id}/members`
**Возвращает:** Список пользователей в комнате

**Файл:** `backend/api/routes.py`

**Добавить код (найдите функцию с routes):**

```python
from fastapi import APIRouter
from sqlmodel import select
from api.models import RoomMember, User, ChatRoom
from api.auth import get_current_user

# Добавьте в конец routes.py:

@router.get("/rooms/{room_id}/members")
async def get_room_members(
    room_id: int,
    session: AsyncSession = Depends(get_session),
    current_user: User = Depends(get_current_user)
):
    """
    Получить список участников комнаты.
    
    Args:
        room_id: ID комнаты
    
    Returns:
        List[dict]: Список участников с информацией о пользователе
    """
    # 1. Проверяем, существует ли комната
    room_result = await session.execute(
        select(ChatRoom).where(ChatRoom.id == room_id)
    )
    room = room_result.scalar_one_or_none()
    
    if not room:
        raise HTTPException(status_code=404, detail="Комната не найдена")
    
    # 2. Получаем всех участников комнаты
    members_result = await session.execute(
        select(RoomMember, User).join(
            User, RoomMember.user_id == User.telegram_id
        ).where(RoomMember.room_id == room_id)
    )
    
    members = members_result.all()
    
    # 3. Форматируем ответ
    return [
        {
            "user_id": member[1].telegram_id,
            "username": member[1].username,
            "full_name": member[1].full_name,
            "joined_at": member[0].joined_at
        }
        for member in members
    ]
```

## 🎯 ШАГ 3: API ENDPOINT - ПРИГЛАСИТЬ ПОЛЬЗОВАТЕЛЯ

### Что нужно?
Эндпоинт для добавления нового участника в комнату.

**Endpoint:** `POST /api/rooms/{room_id}/invite`
**Тело запроса:** `{"telegram_id": 987654321}`
**Возвращает:** `{"message": "User invited successfully"}`

**Добавить в routes.py:**

```python
from pydantic import BaseModel

# Модель для запроса приглашения
class InviteUserRequest(BaseModel):
    telegram_id: int  # ID пользователя, которого приглашаем

@router.post("/rooms/{room_id}/invite")
async def invite_user(
    room_id: int,
    invite_req: InviteUserRequest,
    session: AsyncSession = Depends(get_session),
    current_user: User = Depends(get_current_user)
):
    """
    Пригласить пользователя в комнату.
    
    Проверяет:
    1. Комната существует
    2. Текущий пользователь - создатель комнаты
    3. Приглашаемый пользователь существует
    4. Приглашаемый еще не в комнате
    
    Args:
        room_id: ID комнаты
        invite_req: {"telegram_id": ...}
    """
    
    # 1. Проверяем, существует ли комната
    room_result = await session.execute(
        select(ChatRoom).where(ChatRoom.id == room_id)
    )
    room = room_result.scalar_one_or_none()
    
    if not room:
        raise HTTPException(status_code=404, detail="Комната не найдена")
    
    # 2. Проверяем, что текущий пользователь - создатель комнаты
    if room.created_by != current_user.telegram_id:
        raise HTTPException(
            status_code=403, 
            detail="Только создатель комнаты может приглашать пользователей"
        )
    
    # 3. Проверяем, существует ли приглашаемый пользователь
    invited_user_result = await session.execute(
        select(User).where(User.telegram_id == invite_req.telegram_id)
    )
    invited_user = invited_user_result.scalar_one_or_none()
    
    if not invited_user:
        raise HTTPException(
            status_code=404, 
            detail="Пользователь с таким telegram_id не найден"
        )
    
    # 4. Проверяем, не в комнате ли уже пользователь
    existing_member_result = await session.execute(
        select(RoomMember).where(
            (RoomMember.room_id == room_id) & 
            (RoomMember.user_id == invite_req.telegram_id)
        )
    )
    existing_member = existing_member_result.scalar_one_or_none()
    
    if existing_member:
        raise HTTPException(
            status_code=400, 
            detail="Пользователь уже в комнате"
        )
    
    # 5. Создаем запись о членстве
    new_member = RoomMember(
        room_id=room_id,
        user_id=invite_req.telegram_id
    )
    session.add(new_member)
    
    try:
        await session.commit()
        return {"message": "Пользователь успешно приглашен"}
    except Exception as e:
        # Ловим IntegrityError если вдруг дважды добавили одновременно
        await session.rollback()
        raise HTTPException(
            status_code=400, 
            detail="Не удалось добавить пользователя"
        )
```

### Что нужно?

**Файл:** `frontend/static/room.js`

**Добавить функцию:**

```javascript
// Загрузить участников комнаты
async function loadRoomMembers(roomId) {
  try {
    const response = await fetch(`/api/rooms/${roomId}/members`, {
      method: 'GET',
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('access_token')}`
      }
    });

    if (!response.ok) {
      console.error('Ошибка при загрузке участников');
      return [];
    }

    const members = await response.json();
    displayMembers(members);
    return members;
  } catch (error) {
    console.error('Ошибка:', error);
  }
}

// Отобразить участников
function displayMembers(members) {
  const membersList = document.getElementById('room-members');
  
  if (!membersList) {
    console.warn('Элемент #room-members не найден');
    return;
  }

  membersList.innerHTML = '';

  members.forEach(member => {
    const memberEl = document.createElement('div');
    memberEl.className = 'member-item';
    memberEl.innerHTML = `
      <div class="member-info">
        <strong>${member.full_name || member.username}</strong>
        <span class="member-username">@${member.username}</span>
      </div>
      <span class="joined-at">Присоединился: ${new Date(member.joined_at).toLocaleDateString()}</span>
    `;
    membersList.appendChild(memberEl);
  });
}

// Вызвать при загрузке страницы
document.addEventListener('DOMContentLoaded', () => {
  const roomId = getRoomIdFromUrl(); // получить ID комнаты из URL
  loadRoomMembers(roomId);
});
```

```javascript
// Управление модальным окном
const modal = document.getElementById('invite-modal');
const inviteBtn = document.getElementById('invite-btn');
const closeBtn = document.querySelector('.close');
const confirmBtn = document.getElementById('invite-confirm-btn');
const telegramIdInput = document.getElementById('invite-telegram-id');

  telegramIdInput.value = '';
  telegramIdInput.focus();

// Закрыть модаль
closeBtn.addEventListener('click', () => {
  modal.style.display = 'none';

// Закрыть при клике вне модали
window.addEventListener('click', (event) => {
  if (event.target === modal) {
    modal.style.display = 'none';
  }
});

// Отправить приглашение
confirmBtn.addEventListener('click', async () => {
  const telegramId = parseInt(telegramIdInput.value);

  if (!telegramId || telegramId <= 0) {
    alert('Введите корректный telegram ID');
    return;
  }

  try {
    const roomId = getRoomIdFromUrl();
    const response = await fetch(`/api/rooms/${roomId}/invite`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('access_token')}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ telegram_id: telegramId })
    });

    const data = await response.json();

    if (!response.ok) {
      alert(`Ошибка: ${data.detail || 'Не удалось пригласить пользователя'}`);
      return;
    }

    alert('Пользователь успешно приглашен!');
    modal.style.display = 'none';
    
    // Перезагрузить список участников
    loadRoomMembers(roomId);
  } catch (error) {
    console.error('Ошибка:', error);
    alert('Ошибка при отправке приглашения');
  }
});

// Помощник для получения ID комнаты из URL
function getRoomIdFromUrl() {
  const pathParts = window.location.pathname.split('/');
  return parseInt(pathParts[pathParts.length - 1]);
}
```

## 🐛 РЕШЕНИЕ ЧАСТЫХ ПРОБЛЕМ

### Проблема: "IntegrityError: UNIQUE constraint failed"
**Причина:** UniqueConstraint не был добавлен перед первым созданием таблицы.
**Решение:** Удалить auth.db и перезапустить backend.

### Проблема: "404 - Комната не найдена"
**Причина:** ID комнаты неправильный или комната удалена.
**Решение:** Проверить ID в URL, убедиться что комната существует.

### Проблема: "403 - Только создатель может приглашать"
**Причина:** Вы не создатель комнаты.
**Решение:** Попросить создателя приглашать, или создать свою комнату для теста.

### Проблема: Модаль не закрывается
**Причина:** CSS конфликт или JavaScript ошибка.
**Решение:** Проверить консоль браузера (F12 → Console), посмотреть ошибки.
