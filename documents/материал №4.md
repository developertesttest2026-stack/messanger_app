Задача 7. Что такое база данных?
До сих пор все данные жили в оперативной памяти — как записки на стикерах. При перезапуске сервера они исчезали! Пора построить надёжный сейф.

 Задача 8.  Подключаем SQLite к серверу

 Задача 12. 🔄 Загрузка: присоединяем таблицы
Чтобы показать чат, нужно «собрать» сообщения и имена авторов из двух таблиц.
Что сделать:
1. Модифицируй  GET /messages:
   @app.get("/messages")
   async def get_messages(room: str = "general"):
       conn = sqlite3.connect('chat.db')
       conn.row_factory = sqlite3.Row  # чтобы обращаться к колонкам по имени
       cursor = conn.cursor()
       cursor.execute('''
           SELECT m.id, m.text, m.timestamp, u.username as sender
           FROM messages m
           JOIN users u ON m.user_id = u.id
           WHERE m.room = ?
           ORDER BY m.timestamp
       ''', (room,))
       rows = cursor.fetchall()
       conn.close()
       return [dict(row) for row in rows]
2. На фронтенде: `renderMessages` теперь получает `sender` из ответа — ничего менять не нужно!
💡 Подсказка: `JOIN` — как пазл: соединяет строки из двух таблиц по общему полю (`user_id = id`)
